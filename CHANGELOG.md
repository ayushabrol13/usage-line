# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/).

## [0.1.0] - 2026-10-17

### Added
- Status line under the prompt showing context window fill, 5-hour and weekly plan usage with reset countdowns, and today's spend across all sessions.
- Colour-coded thresholds (green under 60%, yellow 60–84%, red 85% and over).
- `barWidth` and `showToday` options.
